# Задание 1
## Задача 3 (Имена)
### Текст задачи
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество. Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. Создать объекты: Клеопатра; Пушкин Александр Сергеевич; Маяковский Владимир. При выводе не заданные параметры никак не участвуют в образовании строки.

### Алгоритм решения
1. Сделал класс Name. Внутри объявил три переменные типа String (фамилия, имя, отчество). Поставил private final, чтобы их нельзя было случайно поменять снаружи.
2. Написал несколько конструкторов. Тот, который принимает только имя или имя с фамилией, внутри себя просто вызывают главный большой конструктор через this(...), подставляя null туда, где данных не хватает. Так код не дублируется.
3. Переопределил метод toString(). Внутри проверяю каждое поле через if на null. Склеиваю их через StringBuilder. В конце добавил .trim(), чтобы убрать пробелы, если какого-то поля (типа отчества) нет.

## Задача 5 (Дом)
### Текст задачи
Создайте сущность Дом, которая описывается количеством этажей в виде числа. У Дома можно запросить текстовую форму, которая имеет представление вида “дом с N этажами”, где N это число. Гарантировать правильное окончание фразы, в зависимости от количества этажей. Создать и вывести на экран дома с 1, 5, 23 этажами.

### Алгоритм решения
1. Написал класс House с одной переменной int floors для этажей. В конструктор добавил проверку через if: если этажей меньше или ноль, то кидаю ошибку IllegalArgumentException, чтобы программа падала при кривых данных.
2. В методе toString() написал логику для окончаний. Чтобы понять, как склонять слово «этаж», беру остаток от деления числа на 10 и на 100.
3. Прописал условия: если число заканчивается на 11-14, пишем «этажами» (исключение). Если просто на 1 — «этажом». Во всех остальных случаях подставляется «этажами».

# Задание 2 & Задание 3
## Задача 4 (Сотрудники и отделы)
### Текст задачи
Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает. У каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: “Имя работает в отделе Название, начальник которого Имя”. В случае если сотрудник является руководителем отдела, то текстовая форма должна быть “Имя начальник отдела Название”. Измените решение таким образом, чтобы имея ссылку на сотрудника, можно было бы узнать список всех сотрудников этого отдела.

### Алгоритм решения
1. Сделал два класса — Department (Отдел) и Employee (Сотрудник).
2. В отделе храню его название, ссылку на начальника и список ArrayList со всеми сотрудниками. 
3. В конструкторе Сотрудника сразу связал объекты: когда создаем человека и передаем ему отдел, он автоматически добавляет себя в список этого отдела через команду this.department.employees.add(this).
4. Написан метод getColleagues(), который просто лезет в свой отдел и возвращает список всех работающих там людей.
5. В toString() Сотрудника проверяю через if, является ли он начальником. Если да — вывожу одну строку, если обычный рабочий — вывожу строку с именем его начальника через department.manager.name.

# Задание 5
## Задача 5 (Дроби)
### Текст задачи
Создайте сущность Дробь со следующими особенностями: Имеет числитель и знаменатель (целые числа). Дробь может быть создана с указанием числителя и знаменателя. Может вернуть строковое представление вида “числитель/знаменатель”. Может выполнять операции сложения, вычитания, умножения и деления с другой Дробью или целым числом. Результатом операции должна быть новая Дробь (исходные дроби не изменяются). Посчитать выражение f1.sum(f2).div(f3).minus(5).

### Алгоритм решения
1. Написал класс Fraction с числителем и знаменателем. В конструкторе запретил ноль в знаменателе. Если знаменатель отрицательный, то переношу минус наверх к числителю, чтобы потом не путаться в знаках.
2. Для каждого действия (sum, minus, multiply, div) сделал по два метода. Один принимает другую Дробь, второй — обычное число int. Число int внутри метода просто превращаю в дробь со знаменателем 1.
3. Математику считал по обычным школьным правилам (общий знаменатель крест-накрест для сложения и вычитания, перемножение для умножения и деления). Главное — каждый метод возвращает return new Fraction(...), то есть старые дроби не трогаются, а всегда создается новая.
4. Раз методы возвращают новую дробь, их можно вызывать один за другим в одну строчку (цепочкой). Так и посчитал итоговое длинное выражение из задания.
